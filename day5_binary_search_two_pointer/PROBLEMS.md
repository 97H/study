# Day 5 — 이분탐색 / 투 포인터

## 목표
- "정답 자체를 이분탐색"하는 파라메트릭 서치 패턴 익히기 (입국심사, 나무 자르기 유형)
- 정렬된 배열에서 투 포인터로 O(N^2) → O(N) 줄이는 감각

## 추천 문제 (프로그래머스)
- 예산 (레벨1, 이분탐색 워밍업)
- 입국심사 (레벨3, 파라메트릭 서치 — 꼭 풀어볼 것)
- 징검다리 (레벨4, 어려우면 스킵 가능)
- 구명보트 (Day2에서 이어서 — 투 포인터 관점으로 재분석)

## 보조 (백준)
