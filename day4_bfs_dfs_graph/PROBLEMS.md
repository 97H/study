# Day 4 — BFS / DFS / 그래프 기초

## 목표
- 인접리스트로 그래프 구성하는 패턴을 손에 익히기
- BFS = 최단거리(가중치 없을 때), DFS = 모든 경로/연결 탐색이라는 용도 구분 확실히 하기
- 방문 배열(visited) 빠뜨리지 않는 습관

## 추천 문제 (프로그래머스)
- 타겟 넘버 (레벨2, DFS)
- 게임 맵 최단거리 (레벨2, BFS — 격자 그래프)
- 네트워크 (레벨3, DFS/BFS — 연결요소 개수)
- 단어 변환 (레벨3, BFS)
- 여행경로 (레벨3, DFS + 정렬, 살짝 어려움 — 시간 남으면)
