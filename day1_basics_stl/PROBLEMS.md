# Day 1 — STL 기초 & 함수형 문제풀이 적응

## 목표
- `main()` 없이 함수 시그니처만 보고 바로 로직을 짜는 감각 익히기
- `vector`, `string`, `sort`, `map`/`unordered_map` 기본 문법 손에 익히기
- 입출력 신경 안 쓰고 "함수 입력 → 함수 출력"에만 집중하는 연습

## 추천 문제 (프로그래머스, 레벨1)
- 두 정수 사이의 합
- 서울에서 김서방 찾기
- 문자열 내 p와 y의 개수
- 완주하지 못한 선수 (해시맵 첫 연습)
- 폰켓몬 (set/해시)
- 시저 암호
- 문자열 다루기 기본
- 신고 결과 받기 (해시맵 + 문자열 파싱)

## 보조 (백준 — 함수형으로 변형해서 풀어보기)
- 10809 알파벳 찾기
- 1157 단어 공부
- 2941 크로아티아 알파벳 (문자열 처리 감각)
