# Day 7 — 실전 모의고사

## 진행 방법
1. 아래 조건으로 **진짜 시험처럼** 진행 (검색/참고자료 금지, 타이머 필수)
2. 시간: 2.5~3시간
3. 문제 구성 (프로그래머스 레벨 랜덤 4문제, 지금까지 배운 유형 최소 3개 이상 섞이게 직접 고르기)
   - 레벨1 1~2문제 (Day1~2 유형 중)
   - 레벨2 2문제 (Day3~5 유형 중)
   - 레벨3 1문제 (Day4/5/6 유형 중, 여유 있으면)
4. 문제 고르는 팁: 프로그래머스 "코딩테스트 연습" 페이지에서 이번 주에 안 풀어본 것 위주로 고르기

## 실전처럼 지켜야 할 규칙
- [ ] 함수 시그니처 절대 안 바꾸기 (문제에서 주어진 그대로)
- [ ] 변수명 의미 있게, 로직 단위 주석 최소 1줄 이상
- [ ] 어려운 문제 하나에 올인하지 말고, 막히면 다른 문제 먼저 풀고 돌아오기
- [ ] 다 못 풀 것 같으면 브루트포스라도 먼저 제출 형태로 완성 (부분점수 노리기)
- [ ] 마지막 10분은 컴파일 에러/엣지케이스 재점검
