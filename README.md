# SK하이닉스 Solution SW 코딩테스트 1주 완성 플랜

## 시험 특징 (실제 후기 기반)
- **C 또는 C++만 사용 가능**, 채점 환경은 **프로그래머스(programmers.co.kr)**
- **함수 완성형**: `main()`을 직접 짜는 게 아니라 주어진 시그니처의 `solution` 함수를 채움
  - 매개변수/반환형을 절대 바꾸지 않기
  - 정답이 여러 개면 `vector<T>`에 담아 반환
- **주석 & 코드 스타일도 채점 요소** — 변수명, 함수 분리, 최소한의 주석 습관을 지금부터 들일 것
- 문제 수 3~4문제, 난이도는 프로그래머스 레벨 1~2 위주 (가끔 레벨 3)
- "4문제 다 풀어도 불합격"한 사례 있음 → 정답률만큼 **코드 품질/가독성**도 중요

## 준비 원칙
1. **실제 환경과 최대한 비슷하게 연습**: 가능하면 프로그래머스 사이트에서 C++ 로 직접 풀기 (이 디렉토리는 개념 정리 + 로컬 반복 연습용)
2. 이 저장소의 `templates/solution_template.cpp` 형식(함수형 + 주석)에 익숙해지기
3. 매일 배운 유형을 **손으로 직접** 코딩 — 눈으로 읽고 넘어가지 않기
4. 하루 끝에 "오늘 막혔던 지점"을 각 day 폴더 NOTES.md에 한 줄이라도 기록

`../templates/run.sh solution.cpp` 로 컴파일/실행하세요.

```bash

cd day1_basics_stl
../templates/run.sh solution.cpp
```

## 실전 체크리스트 (시험 당일 전 최종 점검)
- [ ] 프로그래머스 사이트에서 C++ 언어 설정, 코드 실행/제출 버튼 위치 익숙한가?
- [ ] `#include <bits/stdc++.h>` 없이도 필요한 헤더(`<vector>`, `<string>`, `<algorithm>`, `<unordered_map>` 등) 아는가?
- [ ] 주어진 함수 시그니처를 절대 바꾸지 않는 습관이 있는가?
- [ ] 변수명을 의미 있게 짓고, 로직 단위로 최소한의 주석을 다는가?
- [ ] 시간복잡도를 입력 크기 보고 먼저 추정하는 습관이 있는가? (예: N ≤ 100,000 → O(N log N) 필요)
- [ ] 엣지케이스(빈 입력, 중복값, 최대/최소 경계값) 확인하는 습관이 있는가?
- [ ] 못 푸는 문제는 부분점수라도 받도록 브루트포스라도 먼저 제출하는 전략을 아는가?
